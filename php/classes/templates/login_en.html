Code
The code used for the login will be shown in the radio (Internet radio → Stations list and there as GUI-Code) The Login will become possible, after the radio has shown the code on its display for the first time. The list of radio stations and podcasts is different for each radio. The list of streams is defined per installation.

Radios can be merged so that two radios share the same station list and the same podcasts. To merge one radio with another, you need to know both codes. Next, log in here using the code of the radio that is to receive the other radio's station list and podcasts, and enter the code of the other radio—to which the current radio is to be added—under Merge. You can undo a merge by logging in here with the code of the radio that does not have its own station list and podcasts and remove the merge.
