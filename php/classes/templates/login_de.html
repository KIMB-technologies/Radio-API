Code
Der Code wird im Menü des Radios angezeigt (Internetradio → Senderliste und dort als GUI-Code). Jedes Radio muss zuerst einmalig die Senderliste aufgerufen und einen Code angezeigt haben, bevor ein Login hier möglich ist. Jedes Radio hat eine eigene Senderliste und eine eigene Liste an Podcasts. Die Liste der Streams ist für den Server fest vorgegeben.

Radios können zusammengelegt werden, sodass dann zwei Radios die gleiche Senderliste und die gleichen Podcasts anzeigen. Um ein Radio mit einem anderen Radio zusammenzulegen, müssen beide Codes bekannt sein. Anschließend loggt man sich mit dem Code des Radios, welches die Senderliste und Podcasts des anderen bekommen soll, hier ein und gibt den Code des anderen, zu dem das aktuelle Radio hinzugefügt werden soll, bei Zusammenlegen ein. Ein Zusammenlegen kann rückgängig gemacht werden, indem man sich mit dem Code des Radios ohne eigene Senderliste und Podcasts hier einloggt und die Zusammenlegung auflöst.
